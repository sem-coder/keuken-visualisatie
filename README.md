# Keuken Visualisatie Tool

Tool om keukenfoto's te visualiseren met verschillende wrap-afwerkingen. Bedoeld voor offertes en klantgesprekken (o.a. keuken wrap).

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Lokaal draaien

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
